# Referência visual (contrato)

- `referencia_visual.html` — **o padrão visual obrigatório** da versão 2. Abra no navegador. As telas Painel, Lançar, Assistente e Projetos do app reproduzem esta grade, cores, tipografia, ícones e espaçamentos.
- `PROMPT_v2.md` — o prompt da versão 2 que originou o padrão.
- `Referencia_Dashboard.png` — o print do dashboard (Hashtag Treinamentos) que deu origem ao padrão.
- `ref_desk_*.png` / `ref_cel_*.png` — a referência renderizada em 1440×900 e 390×844, para comparar lado a lado com `app/capturas/` (`npm run capturas` e `TAMANHO=desktop npm run capturas`).

Para regenerar os PNGs da referência: `cd app && node scripts/capturar-referencia.mjs`.
